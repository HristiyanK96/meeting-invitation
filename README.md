# meeting-invitation

Забавна покана за излизане под формата на „служебна бележка“.

1. Въпросът „Ще излезеш ли с мен?“ има два бутона. Бутонът „Не“ бяга от курсора (или от пръста на телефон) и сменя надписа си. След десет опита сам става „Добре де, ДА 💛“.
2. След „Да“ върху бележката се удря печат „Прието“ и тя избира ден (следващите 14 дни), час и място. Може да напише и свое място, и бележка.
3. Накрая вижда потвърждение и изпраща отговора с един бутон (споделяне в чат или копиране на текста). Може да добави уговорката и в календара си.

Всичко е в един файл: `index.html`. Не трябва сървър и няма зависимости.

## Имената

Отвори `index.html` и попълни `CONFIG` в началото на скрипта:

```js
const CONFIG = {
  herName: "Виолета",        // името ѝ, както стои в графата „До:“
  herNick: "Вили",           // галеното име, с което я поздравява бележката
  myName: "Християн",        // от кого е поканата (в графата „От:“)
  whatsapp: "359888123456",  // по желание: бутон „WhatsApp“ с готовия отговор
  email: "",                 // по желание: бутон „По имейл“
};
```

Имената могат да се подадат и направо в линка, без да пипаш файла:

```
https://<потребител>.github.io/meeting-invitation/?name=Виолета&nick=Вили&from=Иван
```

## Как да я пуснеш онлайн (GitHub Pages)

1. В репото: **Settings → Pages**.
2. **Source: Deploy from a branch**, клон `main`, папка `/ (root)` → **Save**.
3. След минута-две страницата е на `https://<потребител>.github.io/meeting-invitation/`.

Отговорът ѝ се пази само в нейния браузър. За да го научиш, тя натиска „Изпрати ми отговора“ и го праща в чата ви.
